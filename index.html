Your web app, drawn natively on the GPU.

gpuijs runs React, Vue and Solid apps as native desktop apps through GPUI, the UI framework behind the Zed editor. Keep your components and your CSS. Ship no browser engine and no WebView.

Get started Read the docs

import { render } from "@gpuijs/core/react"
import { useState } from "react"

function App() {
  const [todos, setTodos] = useState(initial)
  return (
    <main className="flex flex-col gap-3 p-6">
      <h1 className="title">Todos</h1>
      {todos.map((todo) => (
        <Todo key={todo.id} todo={todo} />
      ))}
    </main>
  )
}

  const [todos, setTodos] = createSignal(initial)

    <main class="flex flex-col gap-3 p-6">

    </main>
  )
}

    No browser inside

    Not Chromium. Not a WebView.

    Electron ships a browser with every app, and Tauri borrows the system's. gpuijs ships neither: your CSS is cascaded, laid out and drawn by a native host.

    Electron

    Bundles Chromium

    Your UI is a web page, rendered by a full browser engine packaged into the app.

    your appChromiumNode.js
    Tauri

    Uses the system WebView

    Your UI is a web page, rendered by the operating system's web engine (WKWebView on macOS).

    your appsystem WebViewRust core
    gpuijs

    No web engine at all

    Your framework runs under Bun. A Rust host built on GPUI runs your CSS and draws every frame with Metal.

    How it works

    From component to pixel

    Two processes and a pipe. Events take the same path back, with browser-like capture and bubbling.

    The app

    Bun

    1. Your components

      React, Vue or Solid, unchanged.

    2. Host nodes

      Lightweight nodes stand in for the DOM.

    3. Commit

      Each batch of changes is encoded as compact binary ops.

    ops
    events

    The host

    Rust

    1. CSS cascade

      Your stylesheet, run over a mirror of the tree.

    2. Layout

      Flexbox, grid and block layout.

    3. Pixels

      Drawn with Metal through GPUI.

    What you get

    The web platform your app uses, made native

    Real CSS

    Selectors, cascade layers, custom properties, calc(), media and container queries, :has(), transitions and keyframes. Tailwind v4 is compiled for you.

    Native text fields

    Inputs are native GPUI fields with IME and dead keys, so typing never waits on JavaScript.

    Electron-style shell

    Window, Menu, app and dialog, with Electron's names. Custom title bars with app-region.

    Your libraries

    Enough of window and document for Radix, MUI, Recharts, ApexCharts, react-router and more.

    One-command packaging

    gpuijs build writes a signed .app, ready to notarize.

    Charts and SVG

    Inline SVG is rasterized sharp at any scale, and hit-tested by shape for chart tooltips.

    Native shell

    The desktop APIs you know from Electron

    Windows, menus, dialogs and the Dock use Electron's names and shapes, carried out with native AppKit through GPUI.

    • Hidden title bars with placed traffic lights
    • Application, Dock and context menus with accelerators
    • Open, save and message dialogs
